## About DoorCE

**DoorCE – Data Opener Open Data for Central Europe** is an Interreg CENTRAL EUROPE project focused on improving the availability, quality, and usability of open data across Central European regions and municipalities.

The project brings together public authorities, research institutions, technology partners, and other organisations to develop practical tools, methodologies, and knowledge supporting the publication and reuse of open data.

More information about the project, its objectives, activities, partners, and results is available on the official project website:

**[DoorCE – Interreg CENTRAL EUROPE](https://www.interreg-central.eu/projects/doorce/)**

## About this repository

### DoorCEInstall

This repository provides the automated deployment procedures, scripts, and repository templates required to set up the DoorCE service and its supporting infrastructure. Within the DoorCE Toolbox, it serves as the foundational setup layer responsible for configuring the host environment, setting up Incus container orchestration, firewall rules, and deploying core services such as Keycloak, CKAN, Traefik, and Dozzle. It is intended for system administrators, DevOps engineers, and partner organisations responsible for hosting and managing DoorCE instances.
